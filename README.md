# BJJ Scoreboard

Настольное табло для соревнований по бразильскому джиу-джитсу. Оператор ведёт одну схватку, отмечает оценки по сигналам судьи и выводит счёт и таймер на экран.

## Запуск из ZIP-архива

Распакуйте `BjjScoreboard-win-x64-single.zip` и запустите `BjjScoreboard.exe` из распакованной папки. Архив предназначен для Windows x64. Среда .NET включена в EXE, а файл `teams.json` рядом с ним можно редактировать для настройки списка команд.

## Запуск из исходников

Для запуска из исходников нужны Windows и .NET SDK 8. Выполните команду из корня репозитория.

```powershell
dotnet run --project BjjScoreboard/BjjScoreboard.csproj
```

В Visual Studio откройте [BjjScoreboard.sln](BjjScoreboard.sln) и запустите проект клавишей **F5**.

## Сборка ZIP-архива

Выполните команды в PowerShell из корня репозитория, чтобы собрать автономный EXE и упаковать его вместе с `teams.json`.

```powershell
$publishDir = 'artifacts/BjjScoreboard-win-x64-single'
dotnet publish BjjScoreboard/BjjScoreboard.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o $publishDir
if ($LASTEXITCODE -ne 0) { throw 'Не удалось собрать BJJ Scoreboard.' }
$packageFiles = @("$publishDir/BjjScoreboard.exe", "$publishDir/teams.json")
Compress-Archive -LiteralPath $packageFiles -DestinationPath "$publishDir.zip" -CompressionLevel Optimal -Force
```

Готовый архив будет в папке `artifacts/`, которую Git игнорирует.

## Управление схваткой

Введите имена спортсменов, выберите команды, укажите пол и весовую категорию. До старта установите длительность основного времени кнопками рядом с надписью **«Время боя (мин)»**. По умолчанию установлено 5 минут.

| Клавиша или кнопка | Действие |
| --- | --- |
| **Пробел** | Запустить, приостановить или продолжить отсчёт. |
| **F11** | Войти в полноэкранный режим или выйти из него. |
| **Enter** | Завершить ввод в текстовом поле и вернуть управление клавиатурой табло. |
| **+2**, **+3**, **+4**, **−1** | Начислить очки или снять одно очко в строке спортсмена. |
| **+** и **−** | Добавить или снять преимущество либо предупреждение в соответствующей колонке. |
| **SUBMISSION** | Отметить победу сабмишеном в строке победителя. |
| **DQ** | Дисквалифицировать спортсмена в его строке и присудить победу сопернику. |
| **Сброс матча** | Очистить данные обоих спортсменов и вернуть таймер к заданной длительности. |

Первое предупреждение увеличивает счётчик штрафов. Второе даёт сопернику одно преимущество, третье — два очка, четвёртое приводит к дисквалификации. При снятии второго или третьего предупреждения соответствующее начисление сопернику снимается.

При сабмишене или дисквалификации табло отображает `50:0` в пользу победителя.

## Golden Score

1. На `00:00` табло сравнивает очки, затем преимущества. Если оба показателя равны, табло объявляет **Golden Score** независимо от количества предупреждений.
2. До запуска Golden Score можно внести оценку за основное время. Если она меняет итог, табло пересчитывает результат основной схватки.
3. По сигналу судьи нажмите **«Начать Golden Score»** или **пробел**. Таймер начинает отсчёт вверх с `00:00` без лимита времени. Очки, преимущества и предупреждения из основного времени сохраняются.
4. Первые начисленные очки или преимущество сразу завершают схватку. Это касается и оценки, начисленной за штраф соперника. Сабмишен и дисквалификация также завершают схватку.

Если результат зафиксирован ошибочно, нажмите **«Отменить результат»**. Табло восстановит очки, преимущества и предупреждения до последнего действия и вернёт Golden Score на паузу. Чтобы продолжить, нажмите **пробел**.

## Список команд

Названия команд задаются в [BjjScoreboard/teams.json](BjjScoreboard/teams.json) в виде массива строк. При сборке файл копируется в папку приложения. Для уже собранной версии можно изменить `teams.json` рядом с исполняемым файлом и перезапустить табло. Если файл отсутствует, пуст или содержит некорректный JSON, приложение загрузит встроенный список.
